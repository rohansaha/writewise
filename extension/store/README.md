# Chrome Web Store assets

Generated by `render-screenshots.cjs`, which drives the extension test harness in Electron
(no real Chrome needed). To regenerate after a UI change:

```bash
npx vite --port 5174 --strictPort &            # serves extension/test/harness.html
npx electron extension/store/render-screenshots.cjs extension/store http://localhost:5174 /tmp/ww-electron-profile
```

- `1-mail-suggestions.png` … `4-chat-autofix.png` – 1280×800 screenshots, upload in this order
- `promo-440x280.png` – small promo tile
- The 128×128 store icon is `../public/icons/icon-128.png`

Listing text, permission justifications and the submission checklist are in [`../STORE_LISTING.md`](../STORE_LISTING.md).
